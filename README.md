# DIU Campus Networking System - CSE314 Project

A comprehensive campus network simulation and architecture designed in Cisco Packet Tracer for CSE314 (Computer Networks) at Daffodil International University.

## 📌 Project Information
* **Course:** CSE314 — Computer Networks
* **Group:** Group 7
* **File:** `Diu Networking System_Group-7.pkt`

## 🌐 Network Features
* **Campus Segmentation:** Structured into academic, administrative, server room, and lab zones using VLANs.
* **IP Addressing & Subnetting:** Hierarchical IPv4 subnet design.
* **Routing & Switching:** Inter-VLAN routing, default gateway routing, and switch port configurations.
* **Network Services:** Integrated DHCP, DNS, and local server configurations.

## 🚀 How to Run
1. Download `Diu Networking System_Group-7.pkt`.
2. Open the file in **Cisco Packet Tracer** (v8.0 or later).
3. Test reachability across subnets using Simulation or Realtime mode.
